# 🤖 Chatbot para WhatsApp

Um bot de atendimento automático para WhatsApp desenvolvido em **Node.js** utilizando a biblioteca `whatsapp-web.js`. O sistema gere interações com clientes, navegação por menus e detalhamento de catálogo de produtos em tempo real.

---

## 🚀 Funcionalidades

- 📱 **Conexão via QR Code:** Autenticação rápida diretamente pelo aplicativo do WhatsApp.
- 💬 **Menu Interativo:** Apresentação de categorias de produtos e opções de navegação.
- 🧠 **Gerenciamento de Contexto:** Identificação do fluxo da conversa para responder a dúvidas sobre itens específicos.
- ⏳ **Persistência de Sessão:** Armazenamento local de credenciais (`LocalAuth`) para evitar reautenticação a cada reinicialização.
- 🛡️ **Filtro de Segurança:** Proteção automática contra respostas indesejadas em grupos e listas de transmissão.

---

## 🛠️ Tecnologias Utilizadas

- [Node.js](https://nodejs.org/)
- [whatsapp-web.js](https://github.com/pedroslopez/whatsapp-web.js)
- [qrcode-terminal](https://www.npmjs.com/package/qrcode-terminal)
